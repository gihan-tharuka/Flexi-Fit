# Flexi-Fit

Flexi-Fit is a Laravel-based fitness center management system powered by Livewire, Filament admin, Tailwind CSS and Vite. This repository contains the application backend, admin UI and frontend assets used in production and development.

## Key features

- User authentication & role-based access control (members, trainers, admins)
- Membership management (plans, subscription status, renewals)
- Workout management (create/edit workouts, routines, exercises)
- Workout progress tracking (measurements, body stats, exercise history)
- Scheduling & bookings (classes, trainer appointments, room/resource booking)
- Payment management & billing (invoices, payments, refunds, gateways)
- Trainer management (profiles, assignments, schedules)
- File & media uploads (images, documents) via Spatie Media Library
- Notifications & emails (reminders for bookings, payments, announcements)
- Admin panel & resource CRUD powered by Filament
- Reporting & analytics (revenue, membership growth, attendance trends)
- Search and filtering for members, workouts, and schedules

This list focuses on the management and operational features implemented or scaffolded in the repository. If you'd like, I can expand any feature above with the exact file locations, routes, Livewire components, or Filament resources used by the project.

## Quick start (local development)

These commands assume you're on Windows PowerShell (the repo root is `Flexi-Fit`). Adjust for bash when on Linux/macOS.

1. Clone the repo and move into it

```powershell
git clone <your-repo-url> Flexi-Fit
cd Flexi-Fit
```

2. Install PHP dependencies

```powershell
composer install
```

3. Copy the environment file and generate an app key

```powershell
copy .env.example .env
php artisan key:generate
```

4. Configure `.env` with your database credentials (see *Environment variables* below)

5. Run database migrations and seeders

```powershell
php artisan migrate --seed
```

6. Create a storage symlink for public media

```powershell
php artisan storage:link
```

7. Install frontend dependencies and start Vite dev server

```powershell
npm install
npm run dev
```

8. Serve the application (development)

```powershell
php artisan serve
# open http://127.0.0.1:8000 in your browser
```


## Environment variables

The project uses the standard Laravel `.env` keys. Important ones used by this project:

- APP_NAME, APP_ENV, APP_URL
- APP_KEY (generated by `php artisan key:generate`)
- DB_CONNECTION, DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORD
- BROADCAST_DRIVER, CACHE_DRIVER, QUEUE_CONNECTION
- MAIL_MAILER, MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD, MAIL_FROM_ADDRESS
- FILESYSTEM_DRIVER (for Spatie media)

Keep secrets out of version control. Use `.env` or a secrets manager in production.

## Deployment notes

Below are recommended steps for deploying to a Linux production host. Adjust services and commands for your environment (containers, PaaS, etc.).

1. Pull code and install dependencies

```bash
composer install --no-dev --optimize-autoloader
npm ci && npm run build
```

2. Set environment variables (production `.env`) and generate key if needed

```bash
php artisan key:generate --force
```

3. Run migrations (use `--force` on production)

```bash
php artisan migrate --force
```

4. Cache and optimize

```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

5. Ensure proper file permissions for `storage/` and `bootstrap/cache`
 
6. Queue workers & scheduler

- Use Supervisor (or systemd) to run `php artisan queue:work --sleep=3 --tries=3` for processing jobs.
- Set the scheduler to run every minute (example cron):

```cron
* * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```
